# Colormons (Cobblemon 1.8.1, NeoForge 1.21.1)

Look at your own Pokemon and press C.

Four groups: Primary, Secondary, Tertiary and Custom. The first three are the biggest
colours in the texture; Custom is filled with the Edit brush.

- Hover a group row to light that group in the map.
- Edit -> pick a group -> click the pixel grid to move pixels into that group.
- Finishes: Default, Glossy, Matte, Shiny.
- Preview on the left shows the texture in your chosen colours.
- Colours are relayed to other players when the server has the mod.

Config: config/colormons.json (set "allowOthers": true to colour any Pokemon)
Masks: assets/colormons/masks/<species>.png (red Primary, green Secondary, blue Tertiary, yellow Custom)
